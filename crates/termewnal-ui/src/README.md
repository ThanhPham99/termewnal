# termewnal-ui (`src`)

## Overview
Desktop GUI binary (`termewnal`) and Iced UI library (`termewnal_ui`) implementing the multi-window terminal workspace, custom terminal viewport widget, split-pane layout tree, left sidebar, interactive SSH/SFTP/tunnel/serial/telnet/Docker workflows, modals, theme engine, single-instance IPC, system tray, and global Quake hotkey integrations.

## Invariants
- **Single-Instance & IPC Framing**: `[main.rs:main]` exits immediately on `LaunchOutcome::SecondaryForwarded`, falls back to `std::env::temp_dir().join("termewnal")` if `ConfigPaths::detect_xdg()` fails (matching `[app.rs:AppState::boot_daemon]`), and falls back to standalone mode (`ipc_handle = None`) on IPC error; `boot_slot` enforces boot-once initialization via `expect`. `[app.rs:AppState::boot_daemon_with_ipc_and_initial_command]` panics if `boot_with_paths` fails and clears `pending_windows` on `IpcCommand::ToggleQuake` while still queuing `pending_remote_connects`. `[ipc.rs:MAX_IPC_FRAME_BYTES]` caps frames at 64 KiB (with `read_frame` rejecting a 4-byte `0`-length header as `IpcError::Protocol`, whereas socket EOF yields `IpcError::Io`), uses a 2-second probe timeout (`[ipc.rs:PROBE_TIMEOUT]`), and runs `BIND_ATTEMPTS` (`3`) stale-socket cleanup iterations plus one final bind/forward attempt (`[ipc.rs:bind_or_forward]`), using `--toggle-quake` precedence in `[ipc.rs:parse_cli_launch_command]`.
- **Window, Workspace, & Close-Guard Lifecycle**: `[window_chrome.rs:main_window_settings]` enforces borderless windows (`decorations: false`, `exit_on_close_request: false`, size >= 200x150); `[app.rs:AppState::restore_from_layout]` clamps restored sizes >= 200x150, degrades non-fatally to empty defaults on malformed auxiliary TOMLs (`quick_commands.toml`, `workspaces.toml`, `sftp_state.toml`, `layout.toml`), skips empty tabs/windows, and clamps split ratios to `[MIN_SPLIT_RATIO, MAX_SPLIT_RATIO]` (`[0.1, 0.9]`), while `Message::WindowResized` clamps tracked sizes >= 100 and `[workspace.rs:Workspace::resize_split]` (delegating to private `SplitNode::resize_split`) rejects non-finite (`!is_finite()`) ratios. `[app.rs:AppState::has_modal_open_in_window]` scopes window modal focus blocking to `has_app_level_modal_open()` plus active-tab `sftp_drawers` modals/context menus, while `[app.rs:AppState::in_flight_os_dialogs]` (`begin_os_dialog`/`end_os_dialog`) prevents Quake `hide_on_blur` while native file/folder pickers are active. `[app.rs:Message::CloseRequested]` hides the Quake window on close; for the last non-Quake window, it hides to tray (`DaemonLifecycle::BackgroundRunning`) when `should_minimize_to_tray_on_close()` is true, enters `CloseGuardState::Confirming` only when `!should_minimize_to_tray_on_close() && BackgroundWorkStatus::has_active_work()`, and closes directly (`window::close(id)`, retiring the final window in `Message::WindowClosed`) when `!has_active_work()`; `TrayAction::Quit` quits directly via `CloseGuardStopAndQuit` (bypassing `Confirming`), whereas `PaletteAction::QuitApp` checks `has_active_work()` even while tray-hidden. `[app.rs:Message::EscapePressed]` dismisses at most one active overlay per press in fixed precedence order.
- **Session, Split, & Input Routing**: `[workspace.rs:WorkspaceIds]` allocates monotonic `TabId`/`PaneId`/`SplitId` values from 1; `[workspace.rs:Workspace::select_tab]`, `set_active_tab_index` (which clamps out-of-range indices), `cycle_tab`, and `focus_session` clear `bell_active`, while `split_pane` (consuming new IDs before target validation) and `close_pane` clear `zoomed_pane`;
