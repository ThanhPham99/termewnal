# crates

## Overview
Cargo workspace member root for Termewnal (configured in [`../Cargo.toml`](../Cargo.toml)). This directory separates headless domain models, persistence, terminal buffering, SSH/SFTP/tunnel engines, and non-SSH protocol drivers from the Iced native desktop UI crate.

## Subdirectories & Boundaries
- `termewnal-core`: [`./termewnal-core/README.md`](./termewnal-core/README.md) — Core domain schemas, XDG `ConfigPaths`, schema-versioned TOML persistence with 3-slot `.bak` rotation, hot-reload watching and recovery, `KeyringSecretStore` and Argon2id + AES-256-GCM `EncryptedVault`, plaintext/encrypted `ConfigSyncService`, quick commands, workspace layouts, SFTP state, keybinding resolution, OpenSSH/Tabby importers, and 28 built-in themes. Verified via `cargo test -p termewnal-core`.
- `termewnal-protocols`: [`./termewnal-protocols/README.md`](./termewnal-protocols/README.md) — Native non-SSH protocol engines (`docker` container discovery and `exec` builders, `serial` sessions with readline/hexdump/newline modes, async TCP `telnet` sessions with IAC negotiation and login scripts, and sans-IO `zmodem` `rz`/`sz` transfer state machine) plus shared `ProtocolStatus` and `ProtocolError`. Verified via `cargo test -p termewnal-protocols`.
- `termewnal-pty`: [`./termewnal-pty/README.md`](./termewnal-pty/README.md) — Cross-platform local shell discovery, native OS PTY session management (`PtySession`), thread-safe `alacritty_terminal::Term` state buffering (`TerminalBuffer`) with configurable `word_separators` and selection extension/clamping helpers, session output logging (`SessionLogger`), expect/send `LoginScriptRunner`, and terminal grid ergonomics (scrollback search, URL/file link detection, POSIX path escaping, SGR/X10 mouse encoding, regex highlights). Verified via `cargo test -p termewnal-pty`.
- `termewnal-ssh`: [`./termewnal-ssh/README.md`](./termewnal-ssh/README.md) — Pure-Rust `russh` SSH transport, authentication (`authenticate_session`), strict `known_hosts` TOFU/MITM verification, `ProxyCommand`/`ProxyJump`/SOCKS5/HTTP `CONNECT` traversal, X11 forwarding, keepalive/clock-jump `ConnectionSupervisor`, server telemetry (`ServerStatsCollector`), resilient `TunnelManager`, and pooled SFTP/resumable `TransferQueue`. Verified via `cargo test -p termewnal-ssh`.
- `termewnal-ui`: [`./termewnal-ui/README.md`](./termewnal-ui/README.md) — Desktop GUI binary (`termewnal`), `termewnal_ui` Iced library, and Windows resource-embedding `build.rs`, implementing the multi-window split-pane workspace, custom `TerminalViewport` (two-pass selection rendering, contrast adjustment, drag auto-scroll), Left Sidebar, per-pane remote-only `SFTP+` panel with embedded `RemoteEditor`, SSH/tunnel/protocol workflows, `ChromePalette` themes, single-instance IPC, Linux X11 global Quake hotkey, and D-Bus tray/notifications. Verified via `cargo test -p termewnal-ui`.
