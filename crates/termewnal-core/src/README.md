# termewnal-core Source Package

## Overview
Core domain schema, configuration, persistence, credential management, hot-reload watching, keybinding resolution, workspace layout, theming, and import/sync subsystem for Termewnal (`termewnal-core`). This package groups 15 Rust source modules (`lib.rs`, `error.rs`, `collections.rs`, `config.rs`, `hot_reload.rs`, `keybindings.rs`, `layout.rs`, `openssh_config.rs`, `profile.rs`, `sftp_state.rs`, `storage.rs`, `sync.rs`, `tabby_importer.rs`, `theme.rs`, and `vault.rs`) that manage XDG path resolution, schema-versioned TOML files with atomic rotation backups, encrypted secrets storage (`KeyringSecretStore` and Argon2id + AES-256-GCM `EncryptedVault`), config file watching/recovery, SSH/Tabby configuration import, and remote config sync.

## Invariants
- **Schema Versioning & Atomic Backup Rotation**:
  - `load_toml_or_default` returns `Ok(T::default())` on `io::ErrorKind::NotFound`; both `load_toml_or_default` and `save_toml_atomic` enforce `schema_version == CURRENT_SCHEMA_VERSION` (`1`), failing with `CoreError::UnsupportedSchemaVersion` before serialization on save (`[storage.rs:load_toml_or_default]`, `[storage.rs:save_toml_atomic]`, `[config.rs:CURRENT_SCHEMA_VERSION]`).
  - `save_bytes_atomic` requires `path.parent()` to be `Some`, stages and `sync_all`s new bytes to a sibling `NamedTempFile` before touching existing files, rotates up to `MAX_BACKUPS = 3` slots (`<target>.bak.1`..`.bak.3`) only if `path.exists()` (`rotate_backups` reads existing bytes into memory, shifts `.bak.2 -> .bak.3` / `.bak.1 -> .bak.2` via `fs::rename`, and stages `.bak.1`, so a mid-rotation failure leaves shifted `.bak.*` files while keeping `target` intact), atomically replaces `path` via `tmp.persist(path)`, and invokes `sync_parent_dir` (which silently ignores `File::open`/`sync_all` errors on Unix) (`[storage.rs:MAX_BACKUPS]`, `[storage.rs:backup_path]`, `[storage.rs:save_bytes_atomic]`, `[storage.rs:rotate_backups]`, `[storage.rs:stage_temp_file]`, `[storage.rs:sync_parent_dir]`).
- **XDG Paths & Bootstrap**:
  - `ConfigPaths::detect_xdg` uses `ProjectDirs::from("io", "termewnal", "Termewnal")` (erroring with `CoreError::MissingXdgDirectories` if absent), resolves `home_dir` via `BaseDirs` or non-empty `HOME` env var, resolves `download_dir` via `UserDirs` or `<data_local_dir>/downloads`, and falls back `ipc_socket_file` from `runtime_dir` to `data_local_dir`; `ConfigPaths::from_root` places `config/`, `data/`, `cache/`, `Some(root/runtime)`, `Some(root)`, and `downloads/` under a single root (`[config.rs:ConfigPaths::detect_xdg]`, `[config.rs:ConfigPaths::from_root]`, `[config.rs:ConfigPaths::ipc_socket_file]`).
  - `ensure_config_files` checks `config.toml` then `profiles.toml`, loading/validating existing files and persisting defaults only for missing files (short-circuiting on a `config.toml` error before checking `profiles.toml`) (`[config.rs:ensure_config_files]`).
  - UI bounds constants (`MIN/MAX_SIDEBAR_WIDTH`, `MIN/MAX_SFTP_PANEL_WIDTH`, opacity `[0.3, 1.0]`) and layout `ratio` (`LayoutSplitNode::Split`), tab-pane indices (`TabLayout::{focused_pane, zoomed_pane}`), and `WorkspaceTemplate::active_tab` are not clamped at deserialization time (`[config.rs:TerminalConfig]`, `[layout.rs:LayoutSplitNode]`, `[layout.rs:TabLayout]`, `[collections.rs:WorkspaceTemplate]`).
- **Hot-Reload Safety & Recovery**:
  - `reload_config_snapshot` and `reload_profiles_snapshot` do not fall back to `Default::default()` on `NotFound` (any `read_to_string` error yields `Err(TomlReloadError { line: None, column: None, backup_available, .. })`), translate TOML error byte spans to 1-based `(line, column)` char offsets, enforce `schema_version == CURRENT_SCHEMA_VERSION`, and report `backup_available` from `backup_path(path, 1).is_file()` (`[hot_reload.rs:reload_toml_snapshot]`).
  - `ConfigReloader::reload_file` preserves the previous valid snapshot if reloading fails, updates `error_for(kind)`, and returns `Ok(true)` only when the newly parsed snapshot differs (`!=`) from the active snapshot (`[hot_reload.rs:ConfigReloader::reload_file]`).
  - `restore_from_backup` reads `<target>.bak.1`, validates TOML and `schema_version` before writing, and overwrites the target via `stage_temp_file` + `tmp.persist` without rotating backups so malformed edits never overwrite `.bak.1` (`[hot_reload.rs:restore_from_backup]`).
  - `ConfigWatcher::start_with_debounce` watches `config_dir` non-recursively with batch mode disabled (`with_batch_mode(false)`), wraps watcher setup errors as `CoreError::Io`, filters debounced events strictly to `config.toml` and `profiles.toml` in a deduplicated `Vec<ConfigFileKind>`, suppresses unrelated filenames, ignores send errors if the receiver drops, and maps non-`Events` batches in `translate_debounced_result` to `ConfigWatchEvent::Rescan` (`[hot_reload.rs:ConfigWatcher::start_with_debounce]`, `[hot_reload.rs:translate_debounced_result]`).
- **Secret Isolation, Vault Format & Auto-Lock**:
  - `Profile`, `SshProxyConfig`, `SshAuthMethod`, and `LoginScriptStep` store non-secret metadata and optional secret reference keys (`vault_secret_ref` / `secret_ref`) rather than raw credentials (`[profile.rs:Profile]`, `[profile.rs:SshAuthMethod]`, `[profile.rs:SshProxyConfig]`, `[profile.rs:LoginScriptStep]`).
  - `validate_secret_ref` rejects empty or whitespace-only refs (`VaultError::InvalidSecretRef`) across `InMemorySecretStore`, `KeyringSecretStore`, and `EncryptedVault` (`[vault.rs:validate_secret_ref]`).
  - `EncryptedVault` uses a 52-byte `HEADER_LEN` binary envelope (`"TMNVLT01"`, format version `1`, Argon2id `m_cost_kib`/`t_cost`/`p_cost`, 16-byte salt, 12-byte nonce) authenticated as AES-256-GCM AAD, wrapping a `"TV1"` length-prefixed UTF-8 payload (`[vault.rs:parse_vault_envelope]`, `[vault.rs:persist_encrypted_vault]`, `[vault.rs:decode_payload]`).
  - `VaultKdfParams::validate` enforces `p_cost > 0`, `t_cost > 0`, `8 * p_cost <= m_cost_kib <= 1_048_576` (defaulting to `19 * 1024` KiB, `t=2`, `p=1`); `EncryptedVault::initialize` rejects empty passwords and pre-existing vault files (`[vault.rs:VaultKdfParams::validate]`, `[vault.rs:EncryptedVault::initialize]`).
  - `EncryptedVault::set_secret` and `delete_secret` require unlocked state (`VaultError::Locked`) and roll back in-memory `entries` if `persist_encrypted_vault` fails (`[vault.rs:EncryptedVault::set_secret]`, `[vault.rs:EncryptedVault::delete_secret]`).
  - Secret material (`VaultKey`, plaintext buffers, `Zeroizing<String>`) is zeroized on lock, unlock replacement, timeout expiration, invalid UTF-8 keyring decoding, and `EncryptedVault::drop`; auto-lock compares `max(monotonic_elapsed, wall_elapsed)` against timeout (`0` or `None` disables timeout; default `30` min), and `VaultSession::apply_config` locks `EncryptedVault` immediately when switching away from `VaultBackend::EncryptedFile` (`[vault.rs:UnlockedVaultState::zeroize_and_clear]`, `[vault.rs:enforce_timeout_locked]`, `[vault.rs:VaultSession::apply_config]`).
- **Config Sync**:
  - `SyncBundle` restricts `files` keys to `ALLOWED_BUNDLE_FILES` (`["config.toml", "profiles.toml", "quick_commands.toml", "workspaces.toml"]`), never reads or writes `Vault` secrets, requires `schema_version == 1`, and parses each TOML entry against its target struct before `apply_to_paths` writes anything (`[sync.rs:ALLOWED_BUNDLE_FILES]`, `[sync.rs:SyncBundle::collect_from_paths]`, `[sync.rs:SyncBundle::validate]`, `[sync.rs:SyncBundle::apply_to_paths]`).
  - `encode_sync_envelope_with_kdf` switches between `SyncEnvelope::Plaintext` and `SyncEnvelope::Encrypted` based on non-empty trimmed passphrase (binding `"TMNSYNC1"` + version + Argon2id params + salt + 12-byte nonce as AES-256-GCM AAD), whereas `decode_sync_envelope` dispatches strictly on the deserialized `SyncEnvelope` JSON mode tag (ignoring `passphrase` for `Plaintext`, requiring a non-empty trimmed passphrase for `Encrypted`) (`[sync.rs:encode_sync_envelope_with_kdf]`, `[sync.rs:decode_sync_envelope]`, `[sync.rs:sync_aad]`).
  - `ConfigSyncService::push` and `pull` reject `SyncProviderKind::None`, perform no ETag/timestamp conflict detection (overwriting remote on push and local on pull), and require HTTP `200..300` status codes; `push` requires a non-empty trimmed passphrase when `encrypt_bundle` is `true` (discarding `passphrase` when `false`) and requires a vault token on `GitHubGist` (creating private gists via `POST` or updating via `PATCH`), whereas `pull` ignores `sync_cfg.encrypt_bundle` and forwards `passphrase` directly to `decode_sync_envelope` (`[sync.rs:ConfigSyncService::push]`, `[sync.rs:ConfigSyncService::pull]`).
- **Profiles, Groups, Tunnels & Collections**:
  - `ProfilesConfig` group operations trim whitespace, treat `"Ungrouped"` (ASCII case-insensitive) as `None`, deduplicate group names ASCII case-insensitively, and reject cross-group renames to existing groups (`[profile.rs:normalize_group_label]`, `[profile.rs:ProfilesConfig::all_groups]`, `[profile.rs:ProfilesConfig::rename_group]`).
  - `Profile::resolve_keepalive` falls back to `AppConfig` keepalive settings; `resolve_mux_attach_command` returns `None` when `auto_attach_mux` is `false`, prefers trimmed `mux_attach_command`, and expands single-token `tmux_reattach` into `tmux attach -t {val} || tmux new -s {val}` (`[profile.rs:Profile::resolve_keepalive]`, `[profile.rs:resolve_mux_attach_command]`).
  - `TunnelRule::requires_public_bind_opt_in` flags `Local`/`Dynamic` rules binding non-loopback/non-`localhost` hosts unless `allow_public_bind` is `true`; `effective_hold_grace` defaults to `10s` (`[profile.rs:is_public_bind_host]`, `[profile.rs:TunnelRule::requires_public_bind_opt_in]`, `[profile.rs:TunnelRule::effective_hold_grace]`).
  - `QuickCommand::payload_bytes` appends `b'\r'` only when `append_newline` is `true` and payload does not already end with `\r` or `\n` (`[collections.rs:QuickCommand::payload_bytes]`).
- **Keybindings, SFTP State & Themes**:
  - `KeyChord::parse` normalizes modifier order (`Ctrl+Shift+Alt+Super+<key>`) and punctuation aliases (`Equal`, `Minus`, `Backslash`, `BracketLeft`, `BracketRight`, `Comma`, `Period`, `Slash`, `F1..F12`, single uppercase ASCII letters), rejecting chords with zero or >1 primary key (`[keybindings.rs:KeyChord::parse]`, `[keybindings.rs:normalize_key_token]`).
  - `KeybindingResolver::resolve_step` checks `[pending_prefix..., next]` preferring `PendingPrefix` over exact `Matched` when a longer sequence shares the prefix, then falling back to `[next]` alone if `pending_prefix` was non-empty; `KeybindingConfig::resolver` iterates `KeyAction::ALL` (47 actions, including `KeyAction::ToggleSidebar => Ctrl+Shift+S`) in two passes prioritizing explicit user overrides before built-in defaults (`[keybindings.rs:KeyAction::ALL]`, `[keybindings.rs:KeybindingConfig::resolver]`, `[keybindings.rs:KeybindingResolver::resolve_step]`).
  - `SftpState` rejects blank `profile_id` or `path` arguments on `record_dir` and bookmark toggles, trims `path` (storing `profile_id` untrimmed) and returns `false` from `record_dir` when unchanged, prevents duplicate bookmarks in `toggle_local_bookmark` / `toggle_remote_bookmark` by removing the first matching entry (`remove(pos)` returning `false`) rather than idempotently inserting, does not deduplicate or filter its `pub` fields on TOML deserialization, and applies no LRU or size limit (`[sftp_state.rs:SftpState]`).
  - `BuiltinTheme::from_name` normalizes ASCII case and strips whitespace/`_`/`-`/`'` across 28 themes and aliases, falling back to `BuiltinTheme::Dark` in `resolve`/`ThemePalette::for_name`; `ThemePalette::with_overrides` silently ignores invalid hex strings and recomputes `is_light` via `is_light_rgb` when `background` is overridden (`[theme.rs:BuiltinTheme::from_name]`, `[theme.rs:ThemePalette::with_overrides]`, `[theme.rs:is_light_rgb]`).
- **OpenSSH & Tabby Importers**:
  - `parse_openssh_config_file` ignores negated, wildcard (`*`, `?`), or whitespace patterns, deduplicates aliases (first-seen wins), strips `"none"` from `ProxyJump`/`ProxyCommand`, defaults port `22`, and maps missing `~/.ssh/config` or missing home dir to `Ok(vec![])` in `load_openssh_hosts_or_empty`/`load_system_ssh_hosts` (`[openssh_config.rs:parse_openssh_config_file]`, `[openssh_config.rs:load_openssh_hosts_or_empty]`, `[openssh_config.rs:load_system_ssh_hosts]`).
  - `parse_tabby_config_str` parses YAML via `noyalib`, keeps only `ssh`/`local`/`serial`/`telnet`/`docker` with required host/port/container fields, resolves hierarchical groups (`" / "`) and jump hosts with cycle detection, flags encrypted/locked Tabby vaults (`TabbyVaultStatus::Locked`), and keeps extracted secrets in private `Zeroizing<String>` entries keyed by `"ssh/{profile_id}"` (`[tabby_importer.rs:parse_tabby_config_str]`, `[tabby_importer.rs:detect_locked_tabby_vault]`, `[tabby_importer.rs:resolve_group_name]`, `[tabby_importer.rs:resolve_tabby_proxy_jumps]`).
  - `import_tabby_into_profiles` deduplicates incoming profiles via `profiles_match_ignoring_ids`, disambiguates unique names via `unique_profile_name`, deduplicates quick commands by `(name, command)`, writes secrets for non-duplicate SSH profiles into `SecretStore`, and records `TabbyCredentialRequirement` when `secret_store` is absent or locked (`[tabby_importer.rs:import_tabby_into_profiles]`).

## Side Effects
- **Filesystem Reads & Writes**:
  - `load_config`, `load_profiles`, `load_layout`, `load_sftp_state`, `load_quick_commands`, `load_workspaces`, and `ensure_config_files` (plus `ConfigReloader::load`) read TOML files from `ConfigPaths` (`[config.rs:load_config]`, `[config.rs:ensure_config_files]`, `[hot_reload.rs:ConfigReloader::load]`, `[profile.rs:load_profiles]`, `[layout.rs:load_layout]`, `[sftp_state.rs:load_sftp_state]`, `[collections.rs:load_quick_commands]`, `[collections.rs:load_workspaces]`).
  - `save_*` functions, `ensure_config_files` / `ConfigReloader::load` (when `config.toml` or `profiles.toml` is missing), `SyncBundle::apply_to_paths`, `ConfigSyncService::push` (`LocalDirectory`), and `save_cloned_openssh_profile` create parent directories, write and `sync_all` temp files, rotate `.bak.1`..`.bak.3` backups, atomically `persist` target files, and invoke `sync_parent_dir` on Unix (`[storage.rs:save_bytes_atomic]`, `[storage.rs:rotate_backups]`, `[storage.rs:sync_parent_dir]`, `[config.rs:ensure_config_files]`).
  - `EncryptedVault::unlock` reads `vault.enc` (`vault_file`), while `initialize`, `set_secret`, and `delete_secret` atomically persist encrypted bytes with `0o600` Unix permissions via `NamedTempFile` (`[vault.rs:EncryptedVault::unlock]`, `[vault.rs:persist_encrypted_vault]`).
  - `parse_openssh_config_file` / `load_system_ssh_hosts` read `~/.ssh/config` (and `Include` targets) read-only; `import_tabby_config_file*` reads Tabby `config.yaml` read-only and `import_tabby_into_profiles` updates `profiles.toml` (and `quick_commands.toml` when new quick commands are added) (`[openssh_config.rs:parse_openssh_config_file]`, `[tabby_importer.rs:import_tabby_config_file]`, `[tabby_importer.rs:import_tabby_into_profiles]`).
  - `reload_*_snapshot` and `restore_from_backup` read TOML and `.bak.1` files; `restore_from_backup` atomically overwrites the target TOML file without rotating backups (`[hot_reload.rs:reload_toml_snapshot]`, `[hot_reload.rs:restore_from_backup]`).
- **OS Environment, Keyring, Watcher & Clocks**:
  - `ConfigPaths::detect_xdg` and `default_tabby_config_path` query OS XDG/user directories (`directories`) and `HOME` (`[config.rs:ConfigPaths::detect_xdg]`, `[tabby_importer.rs:default_tabby_config_path]`).
  - `KeyringSecretStore` reads, writes, and deletes entries in the OS keyring (`keyring::Entry`) or an injected `keyring_core::CredentialStore` (`[vault.rs:KeyringSecretStore]`).
  - `ConfigWatcher::start` / `start_with_debounce` create `config_dir` if absent, spawn an OS filesystem watcher thread (`notify` + `notify_debouncer_mini`), and push `ConfigWatchEvent`s over a `tokio::sync::mpsc::UnboundedSender` (`[hot_reload.rs:ConfigWatcher::start_with_debounce]`).
  - `ClockSample::now` / `SystemVaultClock` and `SyncBundle::collect_from_paths` read OS monotonic (`Instant::now`) and wall (`SystemTime::now`) clocks (`[vault.rs:ClockSample::now]`, `[sync.rs:SyncBundle::collect_from_paths]`).
- **Network Requests, Crypto, RNG & Locks**:
  - `ReqwestSyncHttpClient::send` and `ConfigSyncService::{push, pull}` issue async HTTP `GET`/`PUT`/`POST`/`PATCH` calls via `reqwest::Client` to configured WebDAV URLs or GitHub Gist API endpoints (`https://api.github.com` by default, plus `raw_url` when `file.truncated` is true or `file.content` is `None`) (`[sync.rs:ReqwestSyncHttpClient::send]`, `[sync.rs:ConfigSyncService::push]`, `[sync.rs:ConfigSyncService::pull]`).
  - `EncryptedVault` and `sync.rs` generate random salts/nonces via `rand::rng().fill` and execute Argon2id key derivation (`19 MiB` default, up to `1 GiB` validated in `VaultKdfParams` / `derive_sync_key`) (`[vault.rs:derive_vault_key]`, `[sync.rs:derive_sync_key]`).
  - `Profile`, `TunnelRule`, `QuickCommand`, `WorkspaceTemplate`, `clone_openssh_host_to_profile` / `save_cloned_openssh_profile`, and Tabby import constructors call `Uuid::new_v4()` (`[profile.rs:Profile::local_shell]`, `[collections.rs:QuickCommand::new]`, `[openssh_config.rs:clone_openssh_host_to_profile]`, `[tabby_importer.rs:parse_tabby_config_str]`).
  - `InMemorySecretStore`, `ManualVaultClock`, `EncryptedVault`, and `VaultSession` synchronize state behind `std::sync::Mutex` (`[vault.rs:EncryptedVault]`, `[vault.rs:VaultSession]`).
