# termewnal-pty/src

## Overview
Core implementation of the `termewnal-pty` crate (manifest: [`Cargo.toml`](../Cargo.toml)), providing cross-platform local shell discovery, native OS PTY session management, a thread-safe `alacritty_terminal::Term` state machine (`TerminalBuffer`) reusable across local PTY and remote sessions, session output logging, expect/send login script automation, and terminal grid ergonomics (scrollback search, URL/path link detection, shell path escaping, SGR/X10 mouse encoding, and regex highlight evaluation).

## Interface

  - `[lib.rs:pub mod]` Exposes public submodules `buffer`, `ergonomics`, `error`, `logging`, `login_script`, `session`, and `shell`.
  - `[lib.rs:pub use]` Re-exports external `alacritty_terminal` types (`Scroll`, `Side`, `SelectionType`, `CellFlags`, `TermColor`, `CursorShape`, `NamedColor`, `Rgb`) alongside the primary public symbols from each local submodule.

  - `[buffer.rs:TerminalBuffer]` Wire/stream I/O hooks and feeding: `set_write_sink`, `set_output_interceptor`, `run_output_interceptor`, `feed_bytes`, `feed_terminal_bytes`, `progress`, `clear_screen_and_scrollback`, and `export_scrollback_text`.
  - `[buffer.rs:TerminalBuffer]` Session logging controls: `start_logging(path, strip_ansi)`, `stop_logging`, and `log_path`.

## Invariants
- `[session.rs:TermDimensions::new]` Clamps `cols` and `rows` to at least `1` (`cols.max(1)`, `rows.max(1)`) to satisfy `alacritty_terminal::Term` bounds.
- `[session.rs:PtySpawnConfig::default]` Defaults to `detect_default_shell()`, `80x24`, `scrollback_lines = 10_000`, `CursorShape::Block`, `cursor_blink = false`, `working_dir = None`, and `word_separators = None` (falling back to `alacritty_terminal`'s default `semantic_escape_chars`, which is also preserved in `TerminalBuffer::word_separators` across `apply_options` / `apply_options_with_blink` unless overridden via `apply_options_full`).
- `[buffer.rs:TerminalBuffer::feed_bytes]` No-ops on empty slices; when an `OutputInterceptor` is attached and returns an empty `terminal_bytes` `Vec`, calls `notify_output()` and returns without invoking `feed_terminal_bytes` (so the interceptor is never re-entered).
- `[buffer.rs:TerminalBuffer::feed_terminal_bytes]` Also no-ops on empty slices, silently ignores `logger.write_bytes` errors, and acquires/releases `(osc_parser, progress)`, `logger`, and `(term, processor)` mutexes sequentially before locking `update_signal`, ensuring `term` is never locked while holding `update_signal` in feed paths. Increments `update_signal.0` via `wrapping_add(1)` and emits `PtyEvent::Progress(state)` only when the parsed state differs from the current `progress`. `clear_screen_and_scrollback` feeds hardcoded `b"\x1b[2J\x1b[3J\x1b[H"` directly through `processor.advance` (bypassing `osc_parser`, `logger`, `output_interceptor`, and `Condvar`) before calling `notify_output()`, which wakes `async_notify` and sends `PtyEvent::Output` without notifying `Condvar`.
- `[buffer.rs:OscProgressTracker::osc_dispatch]` Only recognizes `OSC 9;4;<state>;<pct>` (`params.len() >= 3 && params[0] == b"9" && params[1] == b"4"`), mapping codes `0..=4` (`Hidden`, `Normal`, `Error`, `Indeterminate`, `Paused`) and clamping optional progress percentages via `.min(100) as u8` (default `0`).
- `[buffer.rs:TerminalBuffer::take_event_receiver]` Single-shot `Option::take()`; returns `None` if already taken or if `events_rx` mutex is poisoned.
- `[buffer.rs:TerminalBuffer::wait_for_output]` / `[buffer.rs:TerminalBuffer::wait_for_output_async]` Sync waiter holds `update_signal` across `snapshot()` and `Condvar::wait_timeout` (returning `false` directly when `deadline.checked_duration_since(Instant::now())` is `None`, while re-evaluating `predicate(&self.snapshot())` on `wait_res.timed_out()`); async waiter creates `self.async_notify.notified()` before calling `snapshot()` and checking the `exited` flag to avoid lost wakeups, dropping locks before `.await`.
- `[buffer.rs:TerminalBuffer::snapshot]` / `[buffer.rs:snapshot_from_term]` Snapshot `cells` length is `cols * rows` initialized to `TerminalCell::default()` (`' '`, `NamedColor::Foreground`, `NamedColor::Background`, `CellFlags::empty()`), resolves `TermColor::Named`/`TermColor::Indexed` overrides from `content.colors` into `TermColor::Spec`, sets `top_line = -(display_offset as i32)`, and returns `cursor: None` if out of viewport bounds. Most `TerminalBuffer` mutex locks panic via `.expect(...)` if poisoned (except `log_path`, `is_exited`, `take_event_receiver`, and optional logger/write-sink locks).
- `[buffer.rs:TerminalBuffer::export_scrollback_text]` / `[session.rs:TerminalSnapshot::row_text]` / `[session.rs:TerminalSnapshot::visible_text]` `export_scrollback_text` skips `WIDE_CHAR_SPACER | LEADING_WIDE_CHAR_SPACER`, maps `'\0'` to `' '`, trims trailing whitespace per line, and pops trailing empty lines; `row_text` skips `WIDE_CHAR_SPACER`, keeps `cell.c` unchanged (without mapping `'\0'` to `' '`), and trims trailing whitespace on a single row; `visible_text` joins visible `row_text` lines and pops trailing empty lines.
- `[buffer.rs:TerminalBuffer::scroll_to_match]` Keeps `display_offset` unchanged if `target.start.line` is already visible in `[-(display_offset as i32), -(display_offset as i32) + screen_lines - 1]`; otherwise centers near `screen_lines / 2 - target.start.line` clamped to `0..=history_size`.
- `[buffer.rs:clamp_viewport_point]` / `[buffer.rs:TerminalBuffer::extend_or_start_selection]` / `[buffer.rs:TerminalBuffer::finish_selection]` Clamps viewport coordinates to `columns().saturating_sub(1)` / `screen_lines().saturating_sub(1)` before `viewport_to_point`; `extend_or_start_selection` starts a fresh `SelectionType::Simple` anchor when no non-empty selection exists and otherwise reconstructs `Selection` anchored at the farther range endpoint (`Side::Left`/`Side::Right` plus per-axis quadrants for `SelectionType::Block`); `finish_selection` clears `term.selection = None` and returns `None` when `Selection::is_empty()` is true, and both `finish_selection` and `selection_text` filter out empty strings.
- `[session.rs:GridRange::contains]` / `[session.rs:TerminalSnapshot::is_cell_selected]` / `[session.rs:TerminalSnapshot::is_cell_visually_selected]` For non-block (`!is_block`) multi-line selections (`start_line != end_line`), `GridRange::contains` ignores `end_col` on the starting row, ignores `start_col` on the ending row, and spans full width on middle rows, while `is_cell_selected` also checks `(line, col + 1)` when `CellFlags::WIDE_CHAR` is set; `is_cell_visually_selected` preserves exact columns for `Block` and single-line `Simple` selections and otherwise clamps rows via `row_visual_selection_end_col` (`cols - 1` on `WRAPLINE`, `(last_non_space + 1).min(cols - 1)` accounting for wide-char spacers, and `0` on blank lines, keeping `start_col` lit on `start_line` if a multi-line drag began past content end).
- `[session.rs:PtySession::spawn]` Immediately drops `pair.slave` in the parent after spawning so the reader sees EOF when the child exits; initializes `last_working_dir` from `config.working_dir`, and configures `TERM=xterm-256color`, `COLORTERM=truecolor`, and `PtySize` with zero pixel dimensions.
- `[session.rs:PtySession::resize]` Clamps `(cols, rows)` via `TermDimensions::new` first, no-ops when `buffer.dimensions() == (dims.cols, dims.rows)`, panics on poisoned master mutex, resizes `MasterPty` if `Some` (skipping OS resize if `master` is `None`, e.g., post-ConPTY teardown), and always resizes `TerminalBuffer`.
- `[session.rs:PtySession::current_working_dir]` On `#[cfg(target_os = "linux")]` while `!buffer.is_exited()`, prefers `/proc/<child_pid>/cwd`, then `/proc/<fg_pid>/cwd`, before falling back to `osc7_working_dir` and `last_working_dir`.
- `[session.rs:parse_osc7_path]` Accepts `file://<host>/<path>`, `file:///<path>`, or `/`-prefixed paths (rejecting `file://<host>` without a `/` after `<host>`), lossily percent-decodes `%XX` sequences as UTF-8, strips a leading `/` before `<drive>:` on `#[cfg(windows)]`, and rejects empty results.
- `[session.rs:SharedPtyWriter]` Silently succeeds (`Ok(buf.len())` / `Ok(())`) when the inner writer is `None` or its mutex cannot be locked; `[session.rs:PtySession::write_bytes]` panics on poisoned writer mutex and returns `Err(PtyError::WriterClosed)` when `None`.
- `[ergonomics.rs:scan_links_in_logical_line]` Joins rows ending in `CellFlags::WRAPLINE` (trimming trailing `' '`/`'\0'` on unwrapped rows, mapping `'\0'` to `' '`, and skipping `WIDE_CHAR_SPACER | LEADING_WIDE_CHAR_SPACER`), enforces non-overlapping precedence `WebUrl` > `file://` URI > local file path, drops bare scheme-only matches (`"http://"`, `"https://"`, `"file://"`), requires local paths to be `>= 2` chars without leading `"//"` and have an explicit prefix (`/`, `./`, `../`, `~/`), file extension, or `:line`, preserves balanced `()`/`[]` on URLs/`file://` while trimming trailing punctuation unconditionally via `trim_path_suffix` on local paths.
- `[ergonomics.rs:search_term_matches]` Returns empty `Vec` on empty query, tries `RegexSearch::new(query)` then falls back to `RegexSearch::new(&regex::escape(query))`, and steps past `expand_wide(..., Right)` by one cell for non-overlapping matches.
- `[ergonomics.rs:encode_mouse_event]` Encodes 0-based `(col, row)` as 1-based coordinates (`col + 1`, `row + 1`), maps `Left`/`Middle`/`Right`/`WheelUp`/`WheelDown` to base codes `0`/`1`/`2`/`64`/`65` (and non-wheel `Release` to base `3` when `!sgr`), applies button/modifier bitmasks (`Drag=+32`, `shift=+4`, `alt=+8`, `ctrl=+16`), formats `\x1b[<{cb};{x};{y}{m|M}` in SGR mode, and clamps `x`/`y` to `223` before adding `32` (`cb.saturating_add(32)`, `bx`, `by`) in X10 mode.
- `[ergonomics.rs:compile_highlight_rules]` / `[ergonomics.rs:compute_highlight_grid]` Skips disabled, empty-pattern, invalid-regex, or unstyled (`!fg && !bg && !bold`) rules (invalid `RgbColor::from_hex` strings evaluate to `None`, skipping `!r.bold` rules); evaluates per-row `line.trim_end()` text (mapping `'\0'` to `' '` and skipping `WIDE_CHAR_SPACER | LEADING_WIDE_CHAR_SPACER`) independently and lets later matching rules overwrite earlier styles.
- `[ergonomics.rs:shell_escape_path]` Leaves strings unquoted only when non-empty and all bytes match ASCII alphanumeric or `_ - . / : + @ ,`; otherwise wraps in single quotes with `'` escaped as `'\''`.
- `[logging.rs:SessionLogger::write_bytes]` / `[logging.rs:default_session_log_path]` No-ops on empty slices; when `strip_ansi` is true, retains only `Perform::print` UTF-8 text and `b'\n'` / `b'\t'` (writing/flushing only non-empty stripped output); `default_session_log_path` trims `session_title`, sanitizes non-ASCII-alphanumeric/`-`/`_` characters to `_` (default `"session"`), and appends `-{unix_secs}.log` (`0` fallback if clock precedes `UNIX_EPOCH`).
- `[login_script.rs:LoginScriptRunner]` Compiles empty `expect` as immediate, falls back to literal matching if regex compilation fails, resolves non-whitespace `secret_ref` via `SecretStore` (falling back to `step.send` if `vault` is `None` or `get_secret` returns `Err`/`Ok(None)`), appends `b'\r'` when `append_newline` is true and payload does not end with `\r`/`\n`, wraps dispatched/compiled payloads in `Zeroizing<Vec<u8>>`, collects plain text retaining `b'\r'`/`b'\n'`/`b'\t'` in an `8192`-byte UTF-8-aligned window, and drains matched prefixes across multiple consecutive matching/immediate steps in `advance()`.
- `[shell.rs:resolve_unix_shell]` / `[shell.rs:resolve_windows_shells]` / `[shell.rs:detect_default_shell]` `ShellSpec::custom` uses `ShellKind::UnixShell` and `Path::file_name()` as `display_name`; Unix resolution trims `$SHELL`, checks direct existence for `/`-containing paths or `PATH` lookup for bare names, and falls back to `/bin/sh` (`detect_available_shells` probes `["/bin/bash", "/bin/zsh", "/usr/bin/fish", "/bin/sh"]` deduplicating by `program`); Windows probes `Pwsh`, `WindowsPowerShell`, `Cmd`, `GitBash`, `Wsl` (with `%COMSPEC%` or `cmd.exe` fallback).

## Side Effects
- `[buffer.rs:BufferEventProxy::send_event]` / `[buffer.rs:TerminalBuffer::feed_terminal_bytes]` / `[buffer.rs:TerminalBuffer::mark_exited]` Emits `PtyEvent` messages (`Output`, `Title`, `Bell`, `Progress`, `Exited`) on the unbounded Tokio MPSC channel, notifies `Condvar` and `tokio::sync::Notify` waiters, and writes `TermEvent::PtyWrite` responses to the attached `write_sink`.
- `[buffer.rs:TerminalBuffer::run_output_interceptor]` Invokes the mutable `OutputInterceptor` closure and writes/flushes any non-empty wire reply bytes to `write_sink`.
- `[buffer.rs:TerminalBuffer]` Mutates internal `alacritty_terminal::Term` grid, cursor, modes, scroll `display_offset`, and `selection` state (`feed_terminal_bytes`, `clear_screen_and_scrollback`, `resize`, `scroll_display`, `scroll_to_bottom`, `apply_options`, `apply_options_with_blink`, `apply_options_full`, `scroll_to_match`, `start_selection`, `update_selection`, `extend_or_start_selection`, `finish_selection`, `clear_selection`), plus updates `write_sink`, `output_interceptor`, and `events_rx`.
- `[logging.rs:SessionLogger::start]` / `[logging.rs:SessionLogger::write_bytes]` / `[logging.rs:SessionLogger::flush]` / `[buffer.rs:TerminalBuffer::start_logging]` / `[buffer.rs:TerminalBuffer::stop_logging]` Creates parent directories (`fs::create_dir_all`), opens/creates log files in append mode, and writes/flushes bytes to disk; `[logging.rs:default_session_log_path]` reads `SystemTime::now()`.
- `[login_script.rs:LoginScriptRunner::compile]` Queries `termewnal_core::vault::SecretStore::get_secret` for non-empty `secret_ref` steps.
- `[session.rs:PtySession::spawn]` Allocates an OS PTY pair via `portable_pty::native_pty_system().openpty`, spawns the child shell process with `TERM`/`COLORTERM` and optional `cwd`, drops the slave handle, attaches `SharedPtyWriter` to `TerminalBuffer`, and spawns background thread `"termewnal-pty-reader"`.
- `[session.rs:spawn_reader_thread]` Reads PTY master output in 8192-byte chunks (retrying on `ErrorKind::Interrupted`), updates `osc7_working_dir`, feeds `TerminalBuffer`, polls `/proc/<pid>/cwd` on Linux, logs via `tracing::{debug, warn}`, waits for child exit (spawning `"termewnal-pty-waiter"` on Windows to wait and drop writer/master for ConPTY teardown; panics via `.expect` if OS thread spawn fails), and calls `buffer.mark_exited(exit_code)`.
- `[session.rs:PtySession::current_working_dir]` / `[session.rs:read_proc_cwd]` Queries `MasterPty::process_group_leader()` and reads `/proc/<pid>/cwd` symlinks on Linux, updating `last_working_dir`.
- `[session.rs:PtySession::write_bytes]` / `[session.rs:PtySession::resize]` / `[session.rs:PtySession::terminate]` / `[session.rs:PtySession::drop]` Writes/flushes bytes to the PTY master, invokes OS PTY resize (`MasterPty::resize`), clears the writer handle, sends a kill signal via `ChildKiller::kill()`, and notifies output waiters.
- `[shell.rs:detect_default_shell]` / `[shell.rs:detect_available_shells]` / `[shell.rs:find_in_path]` / `[shell.rs:is_usable_executable]` / `[shell.rs:find_executable_on_system]` Reads OS environment variables (`SHELL`, `PATH`, `COMSPEC`, `ProgramFiles`, `SystemRoot`, `LOCALAPPDATA`) and inspects filesystem paths/metadata (and Unix executable permission bits `0o111`).
