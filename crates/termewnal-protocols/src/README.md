# termewnal-protocols Source (`src`)

## Overview
Core implementation of Termewnal's native non-SSH protocol engines inside the `termewnal-protocols` crate. This package provides shared lifecycle/error primitives (`ProtocolStatus`, `ProtocolError`), Docker/Podman container discovery and `exec` `ShellSpec` builders (`docker`), supervised serial port sessions with readline/hexdump/newline modes (`serial`), supervised async TCP Telnet sessions with IAC option negotiation and login scripts (`telnet`), and a sans-IO Zmodem `rz`/`sz` transfer state machine (`zmodem`). Cross-crate types are imported from `termewnal-core`, `termewnal-pty`, `serial2`, `tokio`, `thiserror`, and `tracing`.

## Invariants
- **Docker / Podman (`docker.rs`)**
  - `ContainerExecConfig::from_profile_target` returns `Some` solely for `ProfileTarget::Docker` and `None` for all other variants `[docker.rs:ContainerExecConfig::from_profile_target]`.
  - `build_exec_shell_spec` trims `container`, rejects blank container names/IDs with `ProtocolError::InvalidInput`, omits blank `user`/`working_dir` flags, falls back to `/bin/sh -c "if command -v bash >/dev/null 2>&1; then exec bash; else exec sh; fi"` when `shell` is `None` or blank, and sets `display_name` to `"{docker|podman}: {container}"` `[docker.rs:build_exec_shell_spec]`.
  - `DockerDiscovery::list_containers` invokes `ps` (plus `-a` when `include_stopped`) with `--format "{{.ID}}\t{{.Names}}\t{{.Image}}\t{{.Status}}"`, and `parse_ps_output` trims lines, skips empty lines, splits via `splitn(4, '\t')` into trimmed fields, and drops rows where both `id` and `name` are empty `[docker.rs:DockerDiscovery::list_containers]` `[docker.rs:parse_ps_output]`.
  - `DockerDiscovery::list_all_containers` queries `DockerRuntime::Docker` then `DockerRuntime::Podman` and discards all `Err` results from `list_containers`; `OsCommandRunner::run_stdout` returns `ProtocolError::Docker` on spawn failure or non-success exit status (including signal termination) `[docker.rs:DockerDiscovery::list_all_containers]` `[docker.rs:OsCommandRunner::run_stdout]`.
- **Serial (`serial.rs`)**
  - `SerialConnectConfig::from_profile_target` defaults `reconnect_delay` to `DEFAULT_RECONNECT_DELAY` (`500 ms`); `apply_to_settings` rejects empty/whitespace-only `port`, `baud_rate == 0`, unsupported `data_bits` (outside `5..=8`), and unsupported `stop_bits` (outside `1..=2`) with `ProtocolError::InvalidInput`, maps `set_baud_rate` failures to `ProtocolError::Serial`, and forces raw mode via `settings.set_raw()` `[serial.rs:SerialConnectConfig::from_profile_target]` `[serial.rs:SerialConnectConfig::apply_to_settings]`.
  - `OsSerialPortOpener::open` validates non-blank `config.port` before opening the device, propagates `apply_to_settings` errors ahead of generic open failures, and enforces `READ_TIMEOUT` (`40 ms`) `[serial.rs:OsSerialPortOpener::open]`.
  - `parse_hex_input` accepts whitespace/`,`/`;`/`:` delimiters and optional `0x`/`0X` prefixes, rejecting empty post-prefix tokens, odd hex digit counts per token, or non-hex characters with `ProtocolError::InvalidInput` `[serial.rs:parse_hex_input]`.
  - `SerialReadlineBuffer` caps history at `MAX_READLINE_HISTORY` (`64`), retains history on `reset()`, interprets `ESC [ A`/`ESC [ B` for history recall (consuming other 3-byte `ESC [ <x>` sequences), handles `0x08`/`0x7f` backspace and `0x03` line clear, drops UTF-8 characters split across `feed_input` calls and control bytes `< 0x20` except `\t`, always commits `finished` to `submitted_lines` with `\r\n` local echo in `commit_line`, and skips empty or consecutive duplicate entries only when appending to `history` (`HexBytes` skips empty `parse_hex_input` results and prints `[hex error: {err}]\r\n` to `TerminalBuffer` on invalid hex) `[serial.rs:SerialReadlineBuffer::feed_input]` `[serial.rs:SerialReadlineBuffer::commit_line]`.
  - `SerialActor` exclusively owns `active_stream`, `reader_stop`, and `reader_gen`; `open_current` increments `reader_gen` via `saturating_add(1)` so stale `ReaderEvent` messages are ignored, reader thread ignores `TimedOut`/`WouldBlock`/`Interrupted` and maps `Ok(0)` to `"serial EOF"`, `teardown_stream` stops the reader thread and clears `active_stream` while keeping `buffer`'s write sink across reconnects, and only `Drop` and `SerialActor::run` exit clear `buffer.set_write_sink(None)` `[serial.rs:SerialActor::open_current]` `[serial.rs:SerialActor::teardown_stream]` `[serial.rs:SerialActor::drop]`.
  - `SerialSession::write_bytes` applies `SerialInputMode` (`Text`, `Readline`, `HexBytes`), whereas `send_raw_bytes`, `send_hex`, and `SerialWriteSink` bypass input/newline mode translation; `set_input_mode`/`set_output_mode`/`set_auto_reconnect` guard state resets on actual change; `write_to_stream` runs synchronously on the Tokio actor task; on `RawWire` write failure when `auto_reconnect == false`, `SerialActor::run` sets `ProtocolStatus::Disconnected` and clears the stream without printing a disconnect banner or entering `wait_when_disconnected`; `open_current` failures increment `attempt` whereas stream/write failures reset `attempt = 1`; `wait_reconnect_delay` enforces `>= 10 ms`; `render_incoming` runs `buffer.run_output_interceptor` first and calls `buffer.notify_output()` before returning early on empty output without consuming `reset_hexdump` `[serial.rs:SerialSession::write_bytes]` `[serial.rs:SerialActor::wait_reconnect_delay]` `[serial.rs:SerialActor::render_incoming]`.
- **Telnet (`telnet.rs`)**
  - `TelnetParser::feed` preserves `ParserState` across chunk boundaries via `std::mem::replace`, unescapes `IAC IAC` to `0xFF`, caps subnegotiation buffers at `4096` bytes, transitions directly to `ParserState::Negotiation(other)` if an unescaped `IAC {WILL|WONT|DO|DONT}` interrupts a subnegotiation, and aborts other malformed subnegotiations `[telnet.rs:TelnetParser::feed]`.
  - `escape_telnet_outgoing`, `build_naws_frame`, and `build_ttype_is_frame` escape every `0xFF` payload byte as `[IAC, IAC]`; `TelnetOptionState::initial_offers` immediately sends `IAC WILL {OPT_NAWS, OPT_TTYPE, OPT_SGA, OPT_BINARY}` and `IAC DO OPT_SGA` with `local_will[OPT_NAWS] = true`; `handle_event` replies `build_naws_frame` on `DO NAWS`, replies `TTYPE_IS` on `OPT_TTYPE`/`TTYPE_SEND`, guards supported/unsupported `DO` via `local_announced`, and always replies `IAC DONT` to unsupported `WILL` `[telnet.rs:escape_telnet_outgoing]` `[telnet.rs:TelnetOptionState::initial_offers]` `[telnet.rs:TelnetOptionState::handle_event]`.
  - `TelnetConnectConfig::from_profile_target` clamps `cols`/`rows` with `.max(1)` without validating host/port; `TelnetActor::run` dials `(host, port)` bounded by `connect_timeout`, resets parser/options/login runner on each `'lifecycle` iteration, uses `reconnect_delay.max(10ms)` when `auto_reconnect` is true (suppressing `--- Telnet disconnected (...) ---` on initial connect failure when `auto_reconnect == true`), and clears `buffer.set_write_sink(None)` on exit `[telnet.rs:TelnetConnectConfig::from_profile_target]` `[telnet.rs:TelnetActor::run]` `[telnet.rs:TelnetActor::handle_disconnect_transition]`.
  - Outgoing `TelnetSession::write_bytes` (and `LoginScriptRunner` dispatches) are IAC-escaped, whereas `write_raw_bytes` and `TelnetWriteSink::write` send bytes verbatim; `TelnetSession::resize` passes unclamped `(cols, rows)` to `buffer.resize` while `TelnetCmd::Resize` clamps `.max(1)` and sends `build_naws_frame` while `opts.naws_enabled()` is true; delayed login-script tasks spawned by `schedule_telnet_dispatches` have no cancellation across any disconnect/reconnect cycle and stop only when `cmd_rx` drops on `TelnetActor::run` exit `[telnet.rs:TelnetSession::resize]` `[telnet.rs:schedule_telnet_dispatches]`.
- **Zmodem (`zmodem.rs`)**
  - `ZmodemHeader` encodes `pos` as little-endian `[u8; 4]` and checks/emits big-endian CRC-16 (`ZBin`/`ZHex`, `0x1021`) or little-endian CRC-32 (`ZBin32`, `0xEDB8_8320`), with `ZHex` emitting double `ZPAD` and omitting trailing `XON` for `ZFIN`/`ZACK`; `push_zdle_escaped` escapes `ZDLE`, `DLE`/`0x90`, `XON`/`0x91`, `XOFF`/`0x93`, and `@\r`/`@\x8d` via `byte ^ 0x40` (`encode_subpacket` checks `(b & 0x7f) == b'@'`, whereas `ZmodemHeader::encode` passes `prev_is_at = false`) `[zmodem.rs:ZmodemHeader::encode]` `[zmodem.rs:push_zdle_escaped]` `[zmodem.rs:crc16_xmodem]` `[zmodem.rs:crc32_ieee]`.
  - `sanitize_remote_filename` normalizes `\`, strips directory prefixes, trims leading/trailing control and whitespace characters (retaining interior whitespace/control chars), and falls back to `"zmodem_download.bin"` for empty/`.`/`..` names; `resolve_safe_download_path` probes `"<stem> (<n>).<ext>"` for `1..=10_000` (falling back to `"<stem>_<pid>"` without extension) to avoid overwrites `[zmodem.rs:sanitize_remote_filename]` `[zmodem.rs:resolve_safe_download_path]`.
  - `ZmodemFrameReader` matches 5 consecutive `ZDLE` bytes as `DecodedFrame::Abort`, holds back trailing `ZPAD` prefix bytes in `take_safe_idle_prefix`, buffers subpackets unboundedly in memory (`decode_subpacket_step`), and validates CRCs on `ZBin`/`ZBin32`/`ZHex` headers and subpackets `[zmodem.rs:ZmodemFrameReader::next_frame]` `[zmodem.rs:ZmodemFrameReader::take_safe_idle_prefix]` `[zmodem.rs:ZmodemFrameReader::decode_subpacket_step]`.
  - `ZmodemEngine::start_send` overwrites any active mode and resets `reader` (rejecting empty file lists); `feed_wire` passes `terminal_output` only while `Idle`, strips up to 2 post-`ZFIN` `'O'` bytes via `pending_oo_bytes` (clearing remaining count only if `skip > 0`), reads queued send files lazily on `ZRINIT` (defaulting leaf name to `"upload.bin"`), sends in `SEND_CHUNK_SIZE = 4096` chunks (`u32` / 4 GiB offset cap, skipping `TransferProgress` for 0-byte sends) plus `ZEOF`/`TransferCompleted` synchronously without awaiting `ZACK`, advances on `ZSKIP` without `TransferCompleted`, clamps `ZRPOS`/`ZACK` offsets to `active.data.len()`, ignores `ZABORT`/`ZCAN` in `ReceivingAwaitZdataHeader`, discards `flush()` errors without checking `ZEOF` offsets/sizes, resets to `Idle` + `abort_sequence()` on `cancel()`, returns `Err(err)` immediately on wire errors (discarding `step`), leaves `Sending` active on send file open/read `Err`, and leaves `reader.reading_subpacket == true` without `abort_sequence()` on receive handler `Err` `[zmodem.rs:ZmodemEngine::start_send]` `[zmodem.rs:ZmodemEngine::feed_wire]` `[zmodem.rs:ZmodemEngine::handle_header]` `[zmodem.rs:ZmodemEngine::handle_send_header]`.

## Side Effects
- **Subprocess execution (`docker.rs`)**: `OsCommandRunner::run_stdout` and `DockerDiscovery` invoke `std::process::Command` for `docker ps` and `podman ps` `[docker.rs:OsCommandRunner::run_stdout]` `[docker.rs:DockerDiscovery::list_all_containers]`.
- **OS serial device I/O & background threads (`serial.rs`)**: `list_available_serial_ports` and `OsSerialPortOpener::open` enumerate and open OS serial ports via `serial2::SerialPort` with a 40 ms read timeout; `SerialSession` spawns a Tokio actor task, blocking `spawn_blocking` tasks for open and 4096-byte read polling, allocates `mpsc`/`watch` channels, locks `std::sync::Mutex` state (panicking on poison), installs/clears `TerminalBuffer` write sinks, writes terminal/status/hex-error output into `TerminalBuffer`, and emits `tracing::{debug, warn}` logs `[serial.rs:list_available_serial_ports]` `[serial.rs:OsSerialPortOpener::open]` `[serial.rs:SerialSession::connect_with_opener]` `[serial.rs:SerialActor::open_current]` `[serial.rs:SerialActor::run]`.
- **Network I/O & async tasks (`telnet.rs`)**: `TelnetSession` spawns a Tokio actor task and detached `tokio::spawn` delayed login-script tasks, opens outbound TCP sockets via `tokio::net::TcpStream::connect` with `TCP_NODELAY`, reads/writes/shuts down TCP streams, installs/clears `TerminalBuffer` write sinks, mutates `TerminalBuffer` bytes and dimensions (`resize`), publishes `mpsc`/`watch` updates, and emits `tracing::{debug, warn}` logs `[telnet.rs:TelnetSession::connect_on_buffer]` `[telnet.rs:TelnetActor::run]` `[telnet.rs:schedule_telnet_dispatches]` `[telnet.rs:TelnetSession::resize]`.
- **Filesystem access (`zmodem.rs`)**: `resolve_safe_download_path` probes filesystem existence (`Path::exists`) and `std::process::id()`; `ZmodemEngine` creates `download_dir` (`fs::create_dir_all`), creates/truncates and writes/flushes received files (`File::create`, `BufWriter`), and opens/reads local send files into memory (`File::open`, `read_to_end`) `[zmodem.rs:resolve_safe_download_path]` `[zmodem.rs:ZmodemEngine::handle_subpacket]` `[zmodem.rs:ZmodemEngine::handle_header]` `[zmodem.rs:ZmodemEngine::handle_send_header]`.
